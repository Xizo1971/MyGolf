# MyGolf

Aplicación personal para aprender golf: curso teórico desde cero, notas de las clases con el profesor y, más adelante, análisis del swing con IA. Web en **aprende-golf.com** y, en el futuro, apps para Android e iOS.

- [Hoja de ruta](docs/hoja-de-ruta.md)
- [Documentación técnica](docs/documentacion-tecnica.md)

Uso privado (Miguel y Ana) de momento....

**0.1.0:** curso desde cero con 18 hoyos programados y los 9 de la ida escritos, con 17 dibujos propios (versión para zurdos incluida) y preguntas de repaso. Libreta, Caddie y cuentas llegan en la siguiente entrega.

```
bun install && bun run dev   # http://localhost:8788
bun test
```
