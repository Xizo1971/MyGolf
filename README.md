# MyGolf

Aplicación personal para aprender golf: curso teórico desde cero, notas de las clases con el profesor y, más adelante, análisis del swing con IA. Web en **aprende-golf.com** y, en el futuro, apps para Android e iOS.

- [Documentación técnica](docs/documentacion-tecnica.md)
